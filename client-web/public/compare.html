Why the Difference Matters

💰 80% Creator Fees — Best in Class

Every swap on your token generates LP fees. On PumpClaw, 80% goes to the creator (you or your agent). Bankr gives 57% of a slightly higher fee (1.2%), netting you 0.684%. Clanker gives 40%. For a token doing $10K daily volume, PumpClaw earns ~$80/day vs ~$68 (Bankr) vs ~$40 (Clanker).

🆓 Zero Cost to Launch

PumpClaw deploys tokens for free — no upfront ETH required beyond gas. There's no protocol fee, no minimum stake, no hidden costs. If you're an agent running on a budget, this is the difference between launching and not launching.

🤖 Built for AI Agents

PumpClaw was designed agent-first. Deploy a token with one CLI command, a REST API call, or a direct smart contract interaction. No social media account required. No human in the loop.

# Deploy a token in one command
npx pumpclaw-cli deploy --name "MyToken" --symbol "TKN" --image "https://..."

Clanker requires posting on Farcaster and mentioning @clanker — which means your agent needs a Farcaster account and the social context to trigger deployment. PumpClaw works anywhere: CI/CD pipelines, cron jobs, agent frameworks, or plain curl.

When to Use Clanker

To be fair — Clanker has its strengths:

  • Social virality: Deploying via a Farcaster cast is inherently social. Your followers see the launch in their feed. If your strategy is social-first, Clanker's UX has a built-in distribution advantage.
  • Ecosystem: With 87,000+ tokens deployed, Clanker has a massive ecosystem, its own $CLANKER token, and established integrations with Farcaster clients.
  • Simplicity: For non-technical users, "just mention @clanker" is about as simple as it gets.

When to Use Bankr

Bankr (powered by Whetstone/Doppler) offers a middle ground:

  • Decent creator fees: 57% of 1.2% = 0.684% effective — better than Clanker but still below PumpClaw's 0.80%.
  • DERC20 tokens: Uses a custom token standard with built-in inflation controls (can be disabled via migrate()).

The catch: Bankr uses non-standard DERC20 tokens, Farcaster-only launch, and still takes a larger protocol cut than PumpClaw. If you want standard ERC-20s with maximum creator revenue, PumpClaw wins.

When to Use PumpClaw

  • You want maximum fees — 80% vs 40%, no contest
  • You're an AI agent — CLI/API integration, no social account needed
  • You want control — custom supply, custom creator, updateable images
  • You're building infrastructure — open source, composable, documented API
  • You don't use Farcaster — PumpClaw works from any interface
  • Budget matters — zero launch cost, only gas
